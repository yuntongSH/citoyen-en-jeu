# Contributing

Thank you for helping make French civic knowledge easier to understand.

1. Open an issue describing the learner’s problem or the factual correction. Include a current official source and its date.
2. Propose a focused pull request. Keep French explanations short and clear; label English as a learning aid.
3. For a quiz, write an original question, exactly one unambiguous answer, plausible alternatives and an explanation grounded in a primary source.
4. Run `npm test` and `npm run build`; check keyboard navigation and a narrow screen when changing the interface.

Do not include personal data, credentials, official PDF scans, copied official question banks or unlicensed assets. Contributions must be your own or properly licensed, and are contributed under this project’s MIT licence. Do not claim ministry approval, complete exam coverage or a guaranteed result.

The creator welcomes constructive corrections. In public issues, describe account problems without revealing email addresses, codes, tokens or learning records.
